# DataVault

Sistema de gerenciamento de produtos e estoque desenvolvido em Python, criado como projeto de estudo e evolução prática.

## Roadmap

### v0.1 — Produtos

* [ ] Cadastrar produtos
* [ ] Gerar ID automaticamente
* [ ] Listar produtos
* [ ] Consultar produto
* [ ] Editar produto
* [ ] Excluir produto
* [ ] Salvar dados em arquivo

### v0.2 — Estoque

* [ ] Registrar entradas
* [ ] Registrar saídas
* [ ] Atualizar quantidade em estoque
* [ ] Alertar estoque baixo

### v0.3 — Vendas

* [ ] Registrar vendas
* [ ] Vincular produtos às vendas
* [ ] Atualizar estoque automaticamente
* [ ] Calcular valor total da venda

### v0.4 — Clientes

* [ ] Cadastrar clientes
* [ ] Consultar clientes
* [ ] Associar clientes às vendas

### v0.5 — Relatórios

* [ ] Relatório de estoque
* [ ] Relatório de vendas
* [ ] Produtos mais vendidos
* [ ] Produtos com estoque baixo

### v0.6 — Banco de Dados

* [ ] Migrar arquivos para SQLite
* [ ] Implementar SQL
* [ ] Relacionar tabelas
* [ ] Posteriormente estudar MySQL/PostgreSQL

### v0.7 — POO

* [ ] Refatorar o projeto utilizando classes
* [ ] Criar classes para produtos, clientes e vendas
* [ ] Organizar melhor a estrutura do sistema

### v0.8 — Análise de Dados

* [ ] Utilizar Pandas
* [ ] Gerar análises sobre as vendas
* [ ] Criar visualizações
* [ ] Identificar padrões nos dados

### v1.0 — DataVault

* [ ] Sistema completo de gerenciamento
* [ ] Interface mais organizada
* [ ] Banco de dados

* [ ] Análise de dados
